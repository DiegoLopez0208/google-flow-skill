Google Flow Skill gives your AI agent a CLI for ordered image/video generation
in Google Flow, with reusable references, first/last frames and credit checks.
The source code is free; Google Flow access and generation may cost credits.

## What's new

- Installable Python wheel and source archive with the `google-flow` command.
- `python -m google_flow_skill` works when the executable is not on PATH.
- `--version`, `skill-path` and `examples` commands, with bundled agent manual
  and sample scripts.
- A working Claude marketplace manifest and aligned plugin/package versions.
- Package session/output paths outside `site-packages`; `FLOW_HOME` overrides.
- Corrected frames documentation and standalone-skill runtime setup.
- Clean source distribution, installed-package CI and release automation.

## Install

```sh
python -m pip install "git+https://github.com/DiegoLopez0208/google-flow-skill.git@v2.3.0"
google-flow --version
google-flow login
google-flow credits
```

Requires Python 3.10+, Git for this install route, and Google Chrome. Without
Git, download the wheel below and install it using `python -m pip install`.
The Python package is published here on GitHub; PyPI publication awaits account
and Trusted Publisher setup.

Claude Code:

```text
/plugin marketplace add DiegoLopez0208/google-flow-skill
/plugin install google-flow@diego-google-flow
```

Other agents:

```sh
npx skills add DiegoLopez0208/google-flow-skill --skill google-flow
```

The agent manual installs the Python runtime separately on first use.

## Validation and limits

Packaging and CLI wiring tests run without Chrome, network generation or Flow
credits. This release does not include the original checkout's uncommitted
prompt/browser changes, and does not imply a new live generation test.
Generation needs Chrome; this unofficial integration can break when Flow
changes its UI. Some selectors expect Spanish UI labels. References help but
do not guarantee character continuity; a saved Google session can expire.

The English-captioned MP4 demo uses previously recorded browser footage and
generated output, with editorial captions and edited waits. It is a
demonstration, not a current speed or pricing benchmark.
